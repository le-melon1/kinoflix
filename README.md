# 🎬 KinoFlix — Мгновенный торрент-кинотеатр

Приложение для мгновенного поиска и потокового просмотра фильмов и сериалов с торрентов в интерфейсе полноэкранного видеоплеера в стиле YouTube.

## ✨ Ключевые возможности

1. **Мгновенный выбор фильмов:**
   - Поиск по названию (на русском и английском языках).
   - Прямая поддержка раздач с **[RuTracker.net](https://rutracker.net/forum/index.php)**:
     - Авторизация по логину/паролю или готовой cookie `bb_session`.
     - Поиск по трекеру RuTracker.
     - Возможность просто вставить ссылку на тему с RuTracker (например, `https://rutracker.net/forum/viewtopic.php?t=XXXXX`) в строку поиска.
     - Вставка прямых magnet-ссылок.
   - Встроенный агрегатор популярных открытых трекеров (Rutor) для моментального поиска сразу после запуска без необходимости вводить пароли.

2. **Полноэкранный плеер в стиле YouTube:**
   - Фирменный красный таймлайн с предпросмотром времени при наведении и индикацией закешированного буфера.
   - Полноэкранный режим (`f`) и режим кинотеатра (`t`).
   - Центральная анимация паузы / воспроизведения (как на YouTube).
   - Двойной клик слева / справа для перемотки на 10 секунд назад/вперёд.
   - Плавное исчезновение панели управления и курсора при бездействии.
   - Управление скоростью воспроизведения (0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x).
   - Выбор серий (для сериалов открывается удобный список эпизодов).
   - Поддержка горячих клавиш YouTube: `Пробел`/`k`, `f`, `m`, `j`/`l`, `←`/`→`, `↑`/`↓`, `0`..`9`, `Esc`.
   - Кнопка «В плеере Mac» (мгновенно открывает поток в IINA или VLC, если они установлены).

3. **Защита интернет-канала:**
   - Воспроизведение идёт через выделенный буфер в оперативной памяти (RAM) без износа диска.
   - Автоматическая остановка раздачи и сброс соединений при закрытии видео — интернет не забивается в фоне.
   - В настройках доступен выбор лимитов скорости загрузки и отдачи.

## 🚀 Как запустить

В терминале запустите скрипт:

```bash
cd "/Users/olegvarikov/.gemini/antigravity/scratch/kinoflix"
./run.sh
```

Или дважды кликните по файлу **`Запустить KinoFlix.command`** в Finder.

Приложение откроется в вашем браузере по адресу: **http://localhost:7890**.
