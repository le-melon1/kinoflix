Без ожидания загрузки, без износа диска (воспроизведение из RAM), без необходимости VPN-соединения и с полной кроссплатформенной поддержкой: от мобильных устройств (**iPhone / Android**) до настольных компьютеров (**macOS / Windows**) и ТВ-плееров (**AirPlay / Infuse / VLC**).

## 🌟 Ключевые возможности

### 📱 Кроссплатформенные приложения
* **iOS / Android (PWA):** Моментальная установка в один клик прямо из мобильного браузера (Safari / Chrome) без сторонних магазинов. Работает в полноэкранном режиме с собственной иконкой, splash-экраном и мобильной нижней панелью навигации.
* **macOS Standalone App:** Нативное приложение `.app` с иконкой высокого разрешения в Dock, поддержкой жестов и плавным окном воспроизведения (`dist/KinoFlix.app`).
* **Windows Standalone App:** Нативный рабочий стол для Windows: **[Скачать KinoFlix-Windows-x64.zip](https://github.com/le-melon1/kinoflix/releases/download/v3.2.1/KinoFlix-Windows-x64.zip)**.

### ⚡ Потоковый движок нового поколения
* **Работа без VPN:** Интеллектуальный механизм адаптивного обхода блокировок и прямого сокет-соединения для трекеров и P2P-пиров.
* **Стриминг из оперативной памяти (RAM Buffer):** Все данные буферизуются исключительно в оперативной памяти — ноль лишних операций записи на SSD/HDD.
* **Автоматическое управление ресурсами:** Мгновенный сброс соединений и остановка фоновых торрент-раздач при выходе из плеера или закрытии вкладки.

### 🎥 Умный плеер в стиле Netflix
* **Субтитры на лету (WebVTT):** Автоматическое извлечение и форматирование встроенных субтитров (SRT, ASS, VTT) с возможностью быстрого выбора дорожки (клавиша `C`).
* **Пропуск опенинга (Skip Intro):** Пропуск заставки сериала одним кликом или горячей клавишей `S` / `ы`.
* **Картинка в картинке (PiP):** Просмотр видео в компактном плавающем окне поверх других окон (клавиша `P` / `з`).
* **Аудиодорожки и синхронизация:** Поддержка оригинальных звуковых дорожек, многоканального звука 5.1/7.1, автотранскодирования в AAC и точной регулировки смещения звука (audio sync).
* **Смена качества / релиза (Release Switcher):** Быстрое переключение между раздачами (1080p, 4K HDR, различные студии дубляжа) прямо во время просмотра фильма (клавиша `R` / `к`).
* **Серии и сезоны:** Выдвижная панель эпизодов с авто-переходом на следующую серию и наглядным таймером обратного отсчета.
* **Трансляция на ТВ и внешние плееры:** Поддержка Apple AirPlay, мгновенный экспорт потока в **Infuse**, **VLC**, **IINA**, **PotPlayer** по локальной сети.

### 📚 Персональная медиатека и поиск
* **«Мой список» (Избранное):** Добавление фильмов и сериалов в избранное в один клик.
* **«Продолжить просмотр» (Continue Watching):** Автоматическое сохранение точки остановки и просмотренных серий для каждого фильма.
* **Интеграция с RuTracker.net:** Авторизация по логину/паролю или cookie `bb_session`, поиск по разделам трекера, парсинг постеров и тем, поддержка прямых ссылок `viewtopic.php?t=...`.
* **Агрегатор Rutor:** Моментальный поиск без авторизации прямо из коробки.
* **Голосовой поиск (Voice Search):** Поиск фильмов голосом по нажатию микрофона или клавиши `V`.
* **Менеджер загрузок:** Возможность фонового сохранения любых серий или фильмов для автономного просмотра в пути.
* **Режим Smart TV:** Управление с дивана через стрелки пульта/клавиатуры (D-Pad).
* **Гибкие настройки:** 5 разделов настроек (Воспроизведение, Кэш и буфер RAM, Загрузки, Трекеры, Внешний вид).

## ⌨️ Горячие клавиши (Hotkeys)

| Клавиша | Действие |
| :--- | :--- |
| `Пробел` / `K` | Воспроизведение / Пауза |
| `F` | Полноэкранный режим (Fullscreen) |
| `M` | Заглушить / включить звук (Mute) |
| `S` / `ы` | Пропустить заставку (Skip Intro) |
| `P` / `з` | Режим «Картинка в картинке» (Picture-in-Picture) |
| `C` / `с` | Выбор субтитров (Subtitles menu) |
| `R` / `к` | Меню смены релиза / торрента прямо в плеере |
| `V` | Голосовой поиск фильмов (Voice Search) |
| `←` / `→` или `J` / `L` | Перемотка назад / вперед (по умолчанию 10 сек) |
| `↑` / `↓` | Увеличение / уменьшение громкости на 5% |
| `0` .. `9` | Быстрый переход на 0%–90% продолжительности фильма |
| `Esc` | Выход из меню, полноэкранного режима или закрытие плеера |

## 🚀 Быстрый старт

### 1. Клонирование и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/le-melon1/kinoflix.git
cd kinoflix
```

#### 🪟 Запуск на Windows:
Просто запустите двойным кликом файл **`run.bat`** (или выполните `run.bat` в командной строке).  
Скрипт автоматически создаст виртуальное окружение, установит зависимости, подготовит движок `TorrServer.exe` и откроет кинотеатр в браузере.

#### 🍏 Запуск на macOS / Linux:
```bash
./run.sh
```
> **Для пользователей macOS:** Также можно дважды кликнуть по файлу **`Запустить KinoFlix.command`** в Finder.

После запуска откройте браузер: **`http://localhost:7890`** (или **`http://127.0.0.1:7890`**).

## 📱 Установка на телефон (iOS / Android)

KinoFlix реализован как современное Progressive Web App (PWA):

1. Убедитесь, что телефон подключен к той же Wi-Fi сети, что и компьютер с KinoFlix.
2. Узнайте локальный IP-адрес компьютера (например, `192.168.1.45`).
3. Откройте в браузере телефона адрес: `http://192.168.1.45:7890`.
4. **На iPhone (Safari):** Нажмите кнопку **«Поделиться»** (иконка со стрелочкой) ➡️ выберите **«На экран "Домой"»**.
5. **На Android (Chrome):** Нажмите три точки в углу ➡️ выберите **«Установить приложение»** или **«Добавить на главный экран»**.

На экране появится нативная иконка KinoFlix со всеми возможностями мобильного приложения.

## 💻 Сборка нативных приложений для Desktop

### Сборка приложения для macOS (.app)

Для компиляции автономного `.app` с фирменной иконкой:

```bash
chmod +x build_macos.sh
./build_macos.sh
```

Готовое приложение появится в: `dist/KinoFlix.app`. Вы можете перетащить его в папку **`/Applications`** (Программы).

### Сборка приложения для Windows (.exe)

На Windows в командной строке или PowerShell запустите:

```cmd
build_windows.bat
```

Сборка автоматически установит зависимости, сгенерирует иконки и создаст исполняемый файл: `dist\KinoFlix\KinoFlix.exe`.

## 🛠 Технологический стек

* **Backend:** [FastAPI](https://fastapi.tiangolo.com/), [Uvicorn](https://www.uvicorn.org/), Python 3.10+, HTTPX, Pydantic, SQLite
* **P2P Engine:** [TorrServer MatriX](https://github.com/YouROK/TorrServer) (высокопроизводительный Go-демон)
* **Frontend:** Vanilla JavaScript (ES6+), CSS3 (Netflix Design System, CSS Grid & Flexbox, мобильные Bottom Bar и Safe-Area)
* **Desktop:** [pywebview](https://pywebview.flowrl.com/), [PyInstaller](https://pyinstaller.org/)
* **PWA:** Web App Manifest, Service Worker v2, Retina Icons
